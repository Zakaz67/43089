## Циклы `for` и условия `if`

### 1. Вывод чётных чисел

Файл: [`loops/01_even_numbers.py`](loops/01_even_numbers.py)

**Что делает код:**
1. Создаёт список `numbers` с числами.
2. Устанавливает `sa = 0` — переменную, в которой накапливается сумма.
3. Цикл `for i in numbers` по очереди берёт каждое число из списка. В каждой итерации `i` — текущее число.
4. Условие `i % 2 == 0` проверяет, делится ли число на 2 без остатка. Если да, число чётное.
5. `sa = sa + i` добавляет чётное число к сумме.
6. `print(i)` выводит найденное чётное число.

**Вывод программы:**
```text
12
8
6
4
30
```

**Важный момент:** переменная `sa` в коде получает сумму чётных чисел, равную **60**, но сама сумма не выводится. Сейчас `print(i)` находится внутри `if`, поэтому печатаются отдельные числа. Чтобы увидеть сумму, можно добавить `print(sa)` после цикла — без отступа.

### 2. Подсчёт чисел больше 15

Файл: [`loops/02_count_greater_than_15.py`](loops/02_count_greater_than_15.py)

**Что делает код:**
1. Создаёт список `numbers`.
2. Устанавливает `sa = 0` — здесь это счётчик, а не сумма.
3. Цикл `for i in numbers` перебирает все числа списка.
4. Условие `i > 15` проверяет, больше ли текущее число 15.
5. Если условие истинно, `sa = sa + 1` увеличивает счётчик на единицу.
6. После цикла `print(sa)` выводит количество подходящих чисел.

**Числа, которые больше 15:** `23, 18, 42, 31`.

**Вывод программы:**
```text
4
```

### 3. Подсчёт буквы `m` в строке

Файл: [`loops/03_count_letter_m.py`](loops/03_count_letter_m.py)

**Что делает код:**
1. Записывает строку `"programming"` в переменную `text`.
2. Устанавливает `sa = 0` — счётчик найденных букв.
3. Цикл `for i in text` перебирает строку посимвольно. На каждой итерации `i` содержит один символ.
4. `print(i)` выводит каждый символ с новой строки.
5. Условие `i == "m"` проверяет, равен ли текущий символ строчной букве `m`.
6. При совпадении `sa = sa + 1` увеличивает счётчик.
7. После завершения цикла `print(sa)` выводит количество букв `m`.

В слове `programming` буква `m` встречается **2 раза**.

**Последняя строка вывода:**
```text
2
```

### 4. Подсчёт нечётных чисел

Файл: [`loops/04_count_odd_numbers.py`](loops/04_count_odd_numbers.py)

**Что делает код:**
1. Создаёт список `numbers`.
2. Устанавливает `sa = 0` — здесь это счётчик количества найденных чисел.
3. Цикл `for i in numbers` перебирает числа по очереди.
4. Условие `i % 2 == 1` проверяет, является ли число нечётным.
5. Если число нечётное, `sa = sa + 1` увеличивает счётчик на один, а `print(i)` выводит само число.
6. После цикла `print(sa)` выводит количество нечётных чисел.

**Выведенные числа и итоговое количество:**
```text
11
7
5
13
4
```

Здесь `sa` — **счётчик**, потому что мы прибавляем единицу за каждое подходящее число, а не само число.

### 5. Сумма чётных чисел больше 15

Файл: [`loops/05_sum_even_numbers_greater_than_15.py`](loops/05_sum_even_numbers_greater_than_15.py)

**Что делает код:**
1. Создаёт список `numbers` и начинает сумму с `sa = 0`.
2. Цикл `for i in numbers` перебирает каждый элемент списка.
3. Условие `i > 15 and i % 2 == 0` проверяет сразу два требования: число должно быть больше 15 **и** чётным. Оператор `and` означает, что оба условия должны быть истинными.
4. Для подходящего числа `sa = sa + i` добавляет само число к общей сумме.
5. `print(i)` выводит каждое подходящее число, а `print(sa)` после цикла выводит сумму.

**Вывод программы:**
```text
18
22
30
16
86
```

Итоговая сумма: **86**. Здесь `sa` — **сумма**, потому что к ней прибавляются значения найденных чисел.

### 6. Сумма квадратов нечётных чисел

Файл: [`loops/06_sum_squares_of_odd_numbers.py`](loops/06_sum_squares_of_odd_numbers.py)

**Что делает код:**
1. Создаёт список `numbers` и устанавливает `sa = 0`.
2. Цикл `for i in numbers` перебирает все числа.
3. Условие `i % 2 == 1` оставляет только нечётные числа.
4. Выражение `i**2` возводит текущее число в квадрат. Например, `3**2` равно `9`.
5. `sa = sa + i**2` добавляет квадрат к общей сумме, а `print(i**2)` выводит этот квадрат.
6. После цикла `print(sa)` выводит сумму всех полученных квадратов.

**Вывод программы:**
```text
9
121
49
25
204
```

Итоговая сумма квадратов: **204**.

**Что важно запомнить:**
- `for` перебирает элементы списка или строки.
- `if` проверяет условие.
- `% 2 == 0` проверяет чётность, а `% 2 == 1` — нечётность.
- `sa = sa + 1` обычно считает количество подходящих элементов.
- `sa = sa + i` накапливает сумму самих чисел.
- `sa = sa + i**2` накапливает сумму квадратов чисел.
- `and` позволяет проверить несколько условий одновременно.
